The Rust Programming Language

数据类型

在Rust中，每个值都具有一定的_数据类型_，这个类型告诉Rust所指定的数据是什么类型，从而让Rust知道如何处理这些数据。我们将探讨两种数据类型：标量型和复合型。

请记住，Rust 是一种_静态类型_语言，这意味着它必须知道编译时间所有变量的类型。 编译器通常可以推断我们想根据值使用哪种类型以及我们如何使用它。 在可能有多种类型的情况下， 比如当我们使用 parse 转换一个 String 到数字类型时，在“将猜与秘密数字比较”<! - 忽略 –> 第2章部分，我们必须添加类型注释，就像这样：

#![allow(unused)]
fn main() {
let guess: u32 = "42".parse().expect(“不是数字！”);
}

如果我们不在前面的代码中添加 : u32 这种类型注解，Rust将会显示以下错误，这意味着编译器需要我们从我们这里获得更多信息，以了解我们想要使用的类型是什么：

$ cargo build
   Compiling no_type_annotations v0.1.0 (file:///projects/no_type_annotations)
error[E0284]: type annotations needed
 --> src/main.rs:2:9
  |
2 |     let guess = "42".parse().expect("Not a number!");
  |         ^^^^^        ----- type must be known at this point
  |
  = note: cannot satisfy `<_ as FromStr>::Err == _`
help: consider giving `guess` an explicit type
  |
2 |     let guess: /* Type */ = "42".parse().expect("Not a number!");
  |              ++++++++++++

For more information about this error, try `rustc --explain E0284`.
error: could not compile `no_type_annotations` (bin "no_type_annotations") due to 1 previous error

你会看到其他数据类型的不同的类型注解。

标量类型

一个 scalar 类型代表一个单一的值。必须有四个主要的缩放类型：整数、浮点数、布尔值和字符。 你可以从其他编程语言识别这些语言。让我们跳转到他们在Rust中的工作方式。

整数类型

整数是一种没有小数部分的数字。我们在第2章中使用了一种整数类型，即u32类型。这种类型声明表示与之关联的值应该是一个无符号整数（有符号整数类型的起始符号是i而不是u），并且它占用32位的空间。表3-1展示了Rust中的内置整数类型。我们可以使用这些类型中的任何一种来声明整数值的类型。

表3-1：Rust中的整数类型

长度签名无符号
8 位i8u8
16 位i16u16
32 位i32u32
64 位i64u64
128 位i128u128
依赖于架构isizeusize

每个变式都可以被签名或未签名，并且有一个明确的大小。 signed 和 unsigned 指的是数字是否为负数——换言之， 数字是否需要带有标志(签名)，还是只是正面的数字，因此可以在没有标志(未签名)的情况下表示出来。 这就像在纸上写数字一样：当符号发生时，一个数字用加号或减号表示； 然而，当它安全地假定数字是正数时，它的显示没有签名。 已签名的数字是使用 two’s complete 表示的。

每个有符号变体可以存储从−(2n − 1)到2n − 1−1之间的数字，其中_n_表示该变体使用的位数。因此，i8可以存储从−(27)到27−1之间的数字，即从−128到127。无符号变体可以存储从0到2n−1之间的数字，所以u8可以存储从0到28−1之间的数字，即从0到255。

此外，isize和usize这两个类型取决于程序运行的计算机架构：如果你使用的是64位架构，则为64位；如果你使用的是32位架构，则为32位。

您可以使用表3-2中所示的任何形式来编写整数字面量。请注意，能够表示多种数字类型的数字字面量可以使用类型后缀来表示，例如57u8。此外，数字字面量也可以使用_作为视觉分隔符，以便更易于阅读，例如1_000，其值与明确指定为1000时相同。

表3-2：Rust中的整数字面量

数字字面量例子  示例
十进制98_222

八进制0o77
二进制0b1111_0000
字节(仅u8)b'A'

那么，如何确定使用哪种整数类型呢？如果你不确定，Rust的默认设置通常是一个很好的起点：整数类型的默认值是i32。主要情况下，你会在索引某种集合时使用isize或usize。

整数溢出

让我们说你有一个 u8 类型的变量，它可以保持值在 0 到 255 之间。 如果你试图将变量改变为超出该范围的值，例如256。 整数溢出将会发生，这可能会导致两种行为之一。 当您正在编译调试模式时，Rust 包括检查整数溢出，从而使您的程序在运行时发生了 penic。 当程序退出时必须使用术语_panicking；我们将在“不可恢复的错误带有恐慌！ “ 第9章的部分。

当你正在使用--release的标志编译发布模式时，Rust do not 包括检查会引起恐慌的整数溢出。 相反，如果发生溢出情况，Rust 执行 two 的补充包装。 简而言之，该类型能够保持的最大值“包围”到该类型能够保持的最小值。 如果是u8，则值256变为0，值257变为1，等等。 程序将不会恐慌，但变量的值可能不是你所期望的。 依赖整数溢出的包装行为被认为是一个错误。

要明确处理溢出的可能性，您可以使用标准库提供的方法类原始数字类型：

  • 使用 wrapping_* 方法折叠所有模式，如wrapping_add 。
  • 如果使用 checked_* 方法溢出则返回 None 值。
  • 返回值和布尔值表示是否存在溢出与 overflow_* 方法的关系。
  • 使用 saturating_* 方法在数值的最小值或最大值上饱和度。

浮点类型

Rust 还有两种原始类型的 floating-points 号，这两种类型是小数点数。 俄罗斯的浮点型为“f32”和“f64”，分别为32比特和64比特。 默认类型是 f64 ，因为在现代CPU中，它的速度与f32 大致相同，但能够更加精确。 所有浮点类型都已签名。

这是一个显示浮点数的示例：

Filename: src/main.rs

fn main() {
    let x = 2.0; // f64

    let y: f32 = 3.0; // f32
}

浮点数采用 IEEE-754 标准表示。

数值运算

Rust 支持你所期望的所有数字类型的基本数学操作：添加、减幅、乘数、除数和剩余。 整数除以零截断到最近的整数。下面的代码显示你如何在let语句中使用每个数字操作：

Filename: src/main.rs

fn main() {
    // 添加
    let sum = 5 + 10;

    // 减去
    let difference = 95.5 - 4.3;

    // 乘法
    let product = 4 * 30;

    // 除法
    let quotient = 56.7 / 32.2;
    let truncated = -5 / 3; // 在 -1

    // 剩余的
    let remainder = 43 % 5;
}

这些语句中的每一种表述都使用一个数学操作员，并对一个单一的值进行评估，这个数值随后会被一个变量。 Appendix B 包含Rust 提供的所有操作者列表。

布尔类型

与大多数其他编程语言一样，Rust 中的布尔型有两个可能的值：true和false。 布尔值是大小上的一个字节。布尔值中的布尔类型使用“bool“。例如：

Filename: src/main.rs

fn main() {
    let t = true;

    let f: bool = false; // 带有明确类型的批注
}

使用布尔值的主要方式是通过条件，如if 表达式。 我们将在“控制流程” 部分中的if表达式如何工作。

字符类型

Rust’s char 类型是语言最原始的字母类型。以下是一些申报char 值的例子：

Filename: src/main.rs

fn main() {
    let c = 'z';
    let z: char = “Z”; // 带有明确类型的批注
    let heart_eyed_cat = '😻';
}

请注意，我们使用单引号指定char字母，而不是使用双引号的字符串文字。 Rustow的 char 类型大小为 4 字节，表示Unicode scalar 值，这意味着它可以不只是ASCII。 动态字母；中文、日文和韩文字符；表情和零宽度空间都是Rust中有效的char值。 Unicode scalar值从U+0000到U+D7FF和U+E000到U+10FFFF 不等。 然而，“性质”在Unicode中并不实际上是一个概念。 所以你的人类直觉学习什么是“字符”可能与Rust中的char`不匹配。 我们将在“存储带字符串的 UTF-8 编码文本”在第8章中详细讨论这个主题。

复合类型

_复数类型_可以将多个值分组为一个类型。必须有两个原始的复数类型：管和数组。

元组类型

一个 tuple 是一种将数值与各种类型组合成一个复合类型的一般方式。 小企鹅有固定的长度：一旦申报，他们就不能成长或缩小。

我们通过在圆括号内写一个逗号分隔的值列表来创建一个管道。 管道中的每个位置都有一种类型，管道中不同值的类型不必相同。 我们在此示例中添加了可选类型注释：

Filename: src/main.rs

fn main() {
    let tup: (i32, f64, u8) = (500, 6.4, 1);
}

变量tup 绑定到整个管子，因为管子被视为一个复数元素。 要从管道中获取个别值，我们可以使用匹配模式来摧毁一个管状值，像这样：

Filename: src/main.rs

fn main() {
    let tup = (500, 6.4, 1);

    let (x, y, z) = tup;

    println!("The value of x is: {y}");
}

这个程序首先创建了一个管子，并将它绑定到变量tup中。 它然后使用 let 模式来拍摄tup 并将其变成三个单独的变量：x、y和z。 这个叫做_destructuring_，因为它将单个管子分成三个部分。最后，程序会打印y'的值，即6.4’。

我们还可以通过使用一段时间直接访问管道元素(`. 之后是我们想要访问的值的索引。例如：

Filename: src/main.rs

fn main() {
    let x: (i32, f64, u8) = (500, 6.4, 1);

    let five_hundred = x.0;

    let six_point_four = x.1;

    let one = x.2;
}

这个程序创建了管道x，然后使用各自的指数访问管道的每个元素。 与大多数编程语言一样，导星中的第一个索引是0。

没有任何值的导管有一个特殊的名称，unit。 此值及其对应类型是写入的 () 并表示空值或空返回类型。 表达式如果不返回任何其他值，则隐含返回单位值。

数组类型

拥有多个数值集合的另一种方法是使用 array。 与管道不同，数组的每个元素必须具有相同的类型。 与某些其他语言的阵列不同，阵列的长度是固定的。

我们在一个数组中以逗号分隔的列表在方括号中写入值：

Filename: src/main.rs

fn main() {
    let a = [1, 2, 3, 4, 5];
}

当你想要在堆栈上分配数据时，数组是有用的，与我们迄今看到的其他类型相同。 而不是堆堆(我们将在第四章<讨论堆栈和堆堆更多的堆栈！ - 忽略 –>，或当您想要确保您总是有固定数量的元素时。 尽管如此，数组不像矢量类型那么灵活。 矢量是由标准库提供的类似的收藏类型，它允许大小增减，因为它的内容生活在热器上。 如果你不知道是使用数组还是向量，你应该使用向量。 第8章 更详细地讨论矢量。

然而，当你知道不需要改变元素的数量时，数组更有用。 例如，如果你在一个程序中使用月份的名称， 您可能会使用数组而不是矢量，因为您知道它将永远包含12个元素：

#![allow(unused)]
fn main() {
let months = [“1月”, "2月", “3月”, “4月”, "5月", "6月", “7月”,
              “8月”, “9月”, "10月", "11月", "12月"];
}

你用方括号写入数组的类型，每个元素的类型， 一个分数, 然后是数组中的元素数量, 像这样:

#![allow(unused)]
fn main() {
let a: [i32; 5] = [1, 2, 3, 4, 5];
}

在这里，i32是每个元素的类型。在分号后，数字5表示数组包含五个元素。

您也可以通过指定初始值初始化数组来包含每个元素的相同值。 接下来是分号，然后是方括号内的数组长度，如下所示：

#![allow(unused)]
fn main() {
let a = [3; 5];
}

命名为a的数组将包含5元素，它们将被设置为初始值3。 这与写入 `let a = [3, 3, 3, 3, 3, 3, 3]; 等于更简洁。

数组元素访问

数组是已知的固定大小的单个内存块，可分配在堆栈上。 您可以使用索引访问数组元素，如：

Filename: src/main.rs

fn main() {
    let a = [1, 2, 3, 4, 5];

    let first = a[0];
    let second = a[1];
}

在此示例中，命名为first的变量将得到1的值，因为这是数组中索引[0]的值。 命名为second的变量将在数组中从索引[1]中得到2`的值。

无效的数组元素访问

让我们看看如果你试图访问数组中的一个元素会发生什么。这个数组已经过数组的末尾。 说您运行这个代码，类似于第2章中的猜测游戏，以便从用户那里获得一个数组索引：

Filename: src/main.rs

use std::io;

fn main() {
    let a = [1, 2, 3, 4, 5];

    println!("请输入数组索引。");

    let mut index = String::new();

    io::stdin()
        .read_line(&mut index)
        .expect(“未猜对”);

    let index: usize = index
        .trim()
        .parse()
        .expect(“输入的索引不是数字”);

    let element = a[index];

    println!("索引｛index｝处的元素值为：｛element｝");
}

此代码编译成功。 如果你使用 cargo run 来运行这个代码，请输入 0, 1, 2, 3, 或 4, 程序将在该索引数组中打印相应的值。 如果你输入数组结束后的数字，如10，你会看到这样的输出：

thread 'main' panicked at src/main.rs:19:19:
index out of bounds: the len is 5 but the index is 10
note: run with `RUST_BACKTRACE=1` environment variable to display a backtrace

该程序在尝试使用无效值进行索引操作时出现了运行时错误。程序因错误信息而终止，并未执行最终的println!语句。当您尝试通过索引访问元素时，Rust会检查指定的索引是否小于数组的长度。如果索引大于或等于数组长度，Rust将会引发panic。这种检查必须在运行时进行，尤其是在这种情况下，因为编译器无法知道用户在稍后运行代码时可能会输入什么值。

这是一个展示Rust内存安全原则的实际应用示例。在许多低级语言中，这种检查并不进行，当你提供错误的索引时，可能会访问无效的内存。Rust通过立即终止程序来防止这种错误，而不是允许程序继续运行并访问内存。第9章将进一步讨论Rust的错误处理机制，以及如何编写既可读又安全的代码，避免程序崩溃或允许无效的内存访问。
