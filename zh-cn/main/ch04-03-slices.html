切片类型

_Slices_允许你引用一个连续的元素序列，这个序列属于集合。Slice是一种引用方式，因此它不拥有所有权。

这里有一个简单的编程问题：编写一个函数，该函数接收一个由空格分隔的单词字符串，并返回该字符串中第一个找到的单词。如果函数在字符串中找不到空格，那么整个字符串应该被视为一个单词，因此应该返回整个字符串。

注意：为了引入切片，我们仅假设本节使用 ASCII;关于 UTF-8 处理的更详细讨论见第 8 章[“存储带字符串的 UTF-8 编码文本”]（ch08-02-strings.html#storing-utf-8-encoded-text-with-strings）部分 <!–忽略->–部分。

让我们来分析如何在不使用切片的情况下写出该函数的签名，以理解切片能解决的问题：

fn first_word(s: &String) -> ?

first_word函数的参数类型为&String。我们不需要拥有该参数的所有权，所以这样是可以的。（在Rust的惯用语法中，除非有必要，否则函数不会拥有其参数的所有权，这一点在我们继续阅读的过程中会逐渐明白。）但是，我们应该返回什么呢？实际上，我们无法以某种方式描述字符串的“部分”。不过，我们可以返回单词末尾的索引位置，这个位置通常由一个空格来表示。让我们尝试这样做，如清单4-7所示。

因为我们需要逐个检查String元素，判断某个值是否为空格，所以我们将使用as_bytes方法将String转换为字节数组。

fn first_word(s: &String) -> usize {
    let bytes = s.as_bytes();

    for (i, &item) in bytes.iter().enumerate() {
        if item == b' ' {
            return i;
        }
    }

    s.len()
}

fn main() {}

接下来，我们用“iter”方法在字节数组上创建一个迭代器：

fn first_word(s: &String) -> usize {
    let bytes = s.as_bytes();

    for (i, &item) in bytes.iter().enumerate() {
        if item == b' ' {
            return i;
        }
    }

    s.len()
}

fn main() {}

我们将在第13章中详细讨论迭代器。目前，请注意iter是一个方法，它返回集合中的每个元素；而enumerate则封装了iter的结果，并将每个元素作为元组的一部分返回。从enumerate返回的元组的第一个元素是索引，第二个元素则是对该元素的引用。这种方式比我们自己计算索引要方便得多。

因为enumerate方法返回一个元组，我们可以使用模式来解析这个元组。我们将在第6章中进一步讨论模式。在for循环中，我们指定了一个模式，该模式使用i作为元组的索引，而使用&item来表示元组中的单个字节。由于我们从.iter().enumerate()获取了元素的引用，因此我们在模式中使用了&。

在for循环中，我们通过使用字节字面量语法来查找代表空格的字节。如果找到了空格，我们就返回该位置。否则，我们使用s.len()来返回字符串的长度。

fn first_word(s: &String) -> usize {
    let bytes = s.as_bytes();

    for (i, &item) in bytes.iter().enumerate() {
        if item == b' ' {
            return i;
        }
    }

    s.len()
}

fn main() {}

我们现在有办法找出字符串中第一个单词的末尾索引，但存在一个问题。我们返回的是一个单独的usize值，然而这个值只有在&String的上下文中才具有实际意义。换句话说，由于它是一个与String不同的独立值，因此无法保证它在未来仍然有效。请参考清单4-8中的程序，该程序使用了来自清单4-7中的first_word函数。

这个程序没有任何错误，如果我们在调用 s.clear() 之后使用 word 的话，也会进行编译。 因为word根本没有连接到s的状态，word仍然包含5的值。 我们可以使用变量5来尝试提取第一个单词。 但这将是一个错误，因为我们在 word 中保存了 5 之后，s 的内容已经改变。

在word中，必须担心索引与s中的数据不同步，这既繁琐又容易出错！如果我们编写second_word函数，管理这些索引会更加困难。该函数的签名必须如下所示：

fn second_word(s: &String) -> (usize, usize) {

现在，我们跟踪了一个起始索引和一个结束索引，而且还有更多的值是从特定状态的数据中计算出来的，但这些值与那个状态完全无关。我们有三个不相关的变量在四处游荡，需要保持同步。

幸运的是，Rust有一个解决这个问题的方案：字符串切片。

字符串切片

字符串切片是指对一个String中连续元素的引用，其形式如下：

fn main() {
    let s = String::from("hello world");

    let hello = &s[0..5];
    let world = &s[6..11];
}

与其引用整个String，不如引用hello，它指的是String的一部分，这部分是通过额外的[0..5]位来指定的。我们使用方括号内的范围来创建切片，具体方法是指定[starting_index..ending_index]，其中_starting_index表示切片的起始位置，而_ending_index则比切片的最后一个位置多一个位置。在内部，切片数据结构会存储起始位置的数据。切片的长度等于ending_index减去starting_index。因此，在let world = &s[6..11];的情况下，world将是一个包含指向s中索引为6的字节的指针的切片，其长度值为5。

图4-7以图表的形式展示了这一内容。

图4-7：一个字符串切片，指代String的一部分

在Rust的..范围语法中，如果你想从索引0开始，可以省略两个小数点之前的值。换句话说，这两个值是相等的：

#![allow(unused)]
fn main() {
let s = String::from("hello");

let slice = &s[0..2];
let slice = &s[..2];
}

同样地，如果你的切片包含了String的最后一个字节，那么你可以省略后面的数字。这意味着这两者是相等的：

#![allow(unused)]
fn main() {
let s = String::from("hello");

let len = s.len();

let slice = &s[3..len];
let slice = &s[3..];
}

您还可以同时输入两个值，以提取整个字符串的一部分。所以，这两个值是相等的：

#![allow(unused)]
fn main() {
let s = String::from("hello");

let len = s.len();

let slice = &s[0..len];
let slice = &s[..];
}

注意：字符串切片的范围索引必须位于有效的UTF-8字符边界上。如果您尝试在多字节字符的中间位置进行字符串切片，程序将会因错误而退出。

我们现在拥有一个非常简单的API，而且很难出错，因为编译器会确保对String的引用始终有效。还记得在清单4-8中的程序里出现的错误吗？当时，我们的索引指向了第一个单词的末尾，但随后又清除了字符串，导致索引变得无效。那段代码在逻辑上是不正确的，但当时并没有立即显示出任何错误。只有在我们继续尝试使用那个单词的索引时，问题才会显现出来。一个被清空了的字符串。使用切片会使得这个错误无法被检测到，并且能让我们更早地发现代码中存在问题。如果使用first_word的切片版本，将会引发编译时错误：

回想一下借用规则：如果我们有一个不可变的引用，那么我们就不能同时拥有一个可变的引用。因为clear需要截断String，所以它必须获取一个可变的引用。在调用clear之后，println!使用了word中的引用，因此那个不可变的引用在那个时刻仍然应该是有效的。Rust不允许使用可变的引用。在clear中引用了word中的不可变引用，这两个引用同时存在时会导致编译失败。Rust不仅使我们的API更易于使用，还消除了在编译时出现的整类错误！

字符串字面量作为切片

回顾我们已经谈论过的字符串文献存储在二进制文件中。既然我们知道切片，我们可以正确理解字符串文献：

#![allow(unused)]
fn main() {
let s = "Hello, world!";
}

这里的s的类型是&str: 这是一个指向这个二进制程序的特定点的分割。 这也是为什么字符串的文字不可变；&str是不可变的引用。

其他切片

正如您所想象的那样，字符串切片是特定于字符串的。不过，还有一种更通用的切片类型。考虑这个数组：

#![allow(unused)]
fn main() {
let a = [1, 2, 3, 4, 5];
}

就像我们可能想要引用字符串的一部分一样，我们也可能会想要引用数组的一部分。我们可以这样做：

#![allow(unused)]
fn main() {
let a = [1, 2, 3, 4, 5];

let slice = &a[1..3];

assert_eq!(slice, &[2, 3]);
}

这个切片的类型是 `&[i32]’。 它的工作方式与字符串切片相同，因为它储存了第一个元素和长度。 你将使用这种切片来进行其他收藏。 当我们在第8章中谈论矢量时，我们将详细讨论这些收藏。

摘要

在Rust程序中，所有权、借用和切片的概念能够在编译时确保内存安全。Rust语言让你能够像其他系统编程语言一样控制自己的内存使用。但是，通过让数据的所有者在离开作用域时自动清理该数据，这意味着你不必编写额外的代码来实现这种控制。
