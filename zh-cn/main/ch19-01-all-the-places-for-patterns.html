The Rust Programming Language

所有地方模式可以使用

在Rust中的一些地方弹出模式, 你一直在使用它们, 但没有意识到它! 本节讨论模式有效的所有地点。

“匹配”武器

如第六章所述，我们使用match表达式的武器模式。 形式上，匹配表达式被定义为关键词match，一个要匹配的值， 和一个或多个匹配的武器，如果这种值匹配装甲的模式，则由模式和表达式组成，如果这样：

match VALUE {
    PATTERN => EXPRESSION,
    PATTERN => EXPRESSION,
    PATTERN => EXPRESSION,
}

例如，这里是列表6-5中匹配变量x中选项<i32>值的 match 表达式：

match x {
    None => None,
    Some(i) => Some(i + 1),
}

这个“匹配”表达式中的模式是每个箭头左侧的无'和某些(i)`。

匹配表达式的一个要求是，它们必须是详尽无遗的，因为匹配表达式中值的所有可能性都必须加以考虑。 确保你覆盖所有可能性的一个方法是为最后一支武器拥有一种包罗万象的模式： 一个与任何值匹配的变量名称永远都不会失败，从而覆盖所有剩余的情况。

特定的模式 “_” 将匹配任何东西，但它从未绑定到变量，因此它常常用于最后的匹配臂。 例如，如果您想要忽略未指定的任何值，_ 模式可能是有用的。 我们将在“忽略模式中的数值”稍后在本章中更详细地涵盖_ 模式。

let 语句

在本章之前，我们只是明确讨论了使用 match 和 if let' 的模式， 但事实上，我们在其他地方也使用了模式，包括lett语句中的模式。 例如，请考虑这个直截了当的变量赋值与 let` ：

#![allow(unused)]
fn main() {
let x = 5;
}

每次你都使用了类似这种模式的 let 语句，尽管你可能还没有认识到它！ 更多形式上，我们的语句看起来像这样：

let PATTERN = EXPRESSION;

在诸如let x = 5'等发言中， 在PATTERN slot 中有一个变量名, 变量名称只是一种特别简单的模式形式。 必须将表达式与模式进行比较，并指派它找到的任何名称。 因此，在 let x = 5; 示例中，x 是指“绑定此处匹配的变量x。 因为名称x是整个模式，这个模式实际上意味着“将一切绑定到变量x`，不论是什么值。”

要更清楚地看到let的模式匹配方面, 请考虑列出19-1, 后者使用 let 方法来摧毁管子。

在这里，我们与一种模式相匹配。 Rust 将(1, 2, 3)的值与模式(x, y, z)进行比较，并且看到该值匹配模式-即。 它看到两个元素的数量相同——所以Rust 将 1 绑定到 x 、 2 绑定到 y 和 3 绑定到 z 。 你可以将此管道模式视为嵌套三个单独变量模式。

如果图案中的元素数量不匹配管子中的元素数量， 整体类型不匹配，我们会遇到编译器错误。 例如，清单19-2显示了试图销毁一个带有三个元素的管子变成两个变量，这将无法工作。

尝试编译此代码时出现以下类型的错误：

error[E0308]: mismatched types

2 |     let (x, y) = (1, 2, 3);
  |         ^^^^^^   --------- this expression has type `({integer}, {integer}, {integer})`

条件式 if let 表达式

在第六章中，我们讨论了如何使用 if let 表达式，它主要作为一种更简洁的方式来表达 match 的等效代码，后者只能匹配一种情况。可选地，当 if let 中的模式不匹配时，可以有一个相应的 if let，其中包含要执行的代码。

清单19-3展示了，我们还可以混合使用 if let、 else if 和 else if let 表达式。这样做比使用仅包含一个值的 match 表达式提供了更大的灵活性，因为我们可以表达多个值来与模式进行比较。此外，Rust 并不要求一系列 if let、 else if 和 else if let 条件之间必须相互关联。

列表19-3中的代码决定了基于对几个条件的一系列检查来创建您的背景的颜色。 对于这个示例，我们已经创建了具有硬代码值的变量，一个真正的程序可能会从用户输入中收到这些变量。

如果用户指定了最喜欢的颜色，这种颜色被用作背景。 如果没有指定喜爱的颜色，今天是星期二，背景颜色是绿色的。 否则，如果用户指定他们的年龄为字符串，我们可以成功地解析它作为一个数字， 颜色是紫色或橙色，取决于数字的值。 如果所有这些条件都不适用，背景颜色则为蓝色。

这个有条件的结构使我们能够支持复杂的要求。使用我们这里的硬编码值，这个示例将打印`使用紫色作为背景颜色’。

你可以看到如果我们的话' 也可以引入新的变量，这些变量的阴影与匹配武器可以一样： if let Ok(age) = age 的行引入一个包含Ok变量的新的age变量， 隐藏现有的 age变量。 这意味着我们需要将if age > 30条件放入该区块中：我们不能将这两个条件合并为if let Ok(age) = age && age > 30。 新的age` 我们想要比较的 30 是无效的，除非新范围以大括号开始。

使用 “如果我们的话” 表达式的缺点是，编译器没有选中详尽无遗，而使用 “匹配” 表达式则是这样的。 如果我们省略了最后一个 ’ else’ 块，因而错过了处理一些案例的程序，编译器将不会提醒我们注意可能的逻辑错误。
